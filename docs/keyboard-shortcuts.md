# AI Video Studio Pro — Keyboard Shortcuts

**Version:** 1.0.0 — Phase 18

---

## Playback

| Shortcut | Action |
|---|---|
| `Space` | Play / Pause |
| `[` | Step one frame backward |
| `]` | Step one frame forward |
| `Home` | Jump to start of timeline |
| `End` | Jump to end of timeline |

---

## Timeline Editing

| Shortcut | Action |
|---|---|
| `S` | Split selected clip at playhead |
| `Delete` | Delete selected clip |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `Ctrl + S` | Save project (manual) |

---

## Timeline Navigation

| Shortcut | Action |
|---|---|
| `Ctrl + Scroll` | Zoom timeline in / out |
| `Scroll` | Scroll timeline horizontally |

---

## App Actions

| Shortcut | Action |
|---|---|
| `Ctrl + E` | Open Export dialog |

---

## Notes

- All shortcuts are active when the editor window is focused.
- The timeline must have keyboard focus for editing shortcuts (`S`, `Delete`) to trigger — click on the timeline area first.
- Undo/redo history is capped at 100 steps (configurable in Settings → Editor).
